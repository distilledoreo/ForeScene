# Help Center content map

The in-app Help Center is organized into four navigation groups:

- **Start here**: getting started and app-shell controls.
- **Workspaces**: Build, Reference, Shots, Export, and the standalone 360 viewer.
- **Project & guidance**: project backups, Project Safety & Recovery, and Current Objective workflows.
- **Reference**: keyboard shortcuts, compatibility/performance boundaries, and troubleshooting.

Within each section, feature groups are collapsed by default. Search opens matching groups and filters down to matching controls. Primary workspace sections include an **Open** action that returns directly to that workspace.

The catalog deliberately uses the exact labels visible in the app wherever possible. This makes the search box useful when a user knows the control name but not its location or purpose.
