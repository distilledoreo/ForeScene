# Shot / camera templates

| Template | Notes |
|----------|-------|
| establishing | Very wide environment |
| wide | Environment + figures |
| full | Full body |
| medium | Waist-up |
| medium_close_up | Chest-up |
| close_up | Head/shoulders |
| extreme_close_up | Face detail |
| two_shot | Needs ≥2 camera.subjects |
| over_the_shoulder | Needs foregroundSubject |
| insert | Prop/detail |
| profile | Side angle |
| low_angle | Hero / power |
| high_angle | Looking down |
| overhead | Top-down |

Angles: `front`, `three_quarter`, `profile`, `rear`.
Lens classes: `wide`, `normal`, `long`.
