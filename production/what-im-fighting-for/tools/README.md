# What I'm Fighting For production helpers

These are project-specific, work-in-progress helpers for the **What I'm
Fighting For** production. They are not part of the supported ForeScene Agent
CLI or the reusable `forescene-previs` skill, and no package script invokes
them.

Keep production assumptions, assets, and shot-specific automation here. Do
not use these helpers as a template for a new production or treat their output
as verified without the separate runtime validation work.
