# What I'm Fighting For production material

This directory isolates one production's manifests and work-in-progress
automation from ForeScene's supported Agent CLI and reusable skills.

- `manifests/` contains the production-specific music-video manifest.
- `tools/` contains production-specific helper scripts and their operating
  notes.

Do not use these files as generic ForeScene examples or regard their output as
validated without the separate runtime verification work.
